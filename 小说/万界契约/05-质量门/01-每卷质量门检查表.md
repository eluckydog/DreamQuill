# 每卷质量门检查表

> 每卷写完后，写手（或校对师）用此表检查。不通过不得交付下一卷。

---

## 检查项

### 1. 字数合规

| 检查项 | 标准 | 判定 | 不通过处理 |
|--------|------|------|-----------|
| 本卷总字数 | 目标±15% | □ 通过 □ 不通过 | 超出→删减过渡段；不足→补充场景 |
| 每章字数 | 区间内 | □ 通过 □ 不通过 | 单章超20%→确认是否有实质内容，否则压缩 |
| 单场景字数 | 自然容量±30% | □ 通过 □ 不通过 | 超出→检查是否注水；不足→检查功能是否实现 |

### 2. 人设一致性

| 检查项 | 方法 | 判定 |
|--------|------|------|
| 主角言行是否符合人设 | 抽取3处对话/行为对照角色锚 | □ 通过 □ 不通过 |
| 所有出场配角言行是否符合人设 | 每角色抽取1处 | □ 通过 □ 不通过 |
| 是否有"为推进剧情让人物降智" | 通读检查 | □ 通过 □ 不通过（最常见的问题） |

### 3. 因果链完整性

| 检查项 | 标准 | 判定 |
|--------|------|------|
| 本卷应覆盖的主链节点 | 全部实现 | □ 通过 □ 不通过 |
| 节点间因果关系清晰 | 不存在"突然出现"的事件 | □ 通过 □ 不通过 |
| 跨卷因果衔接正确 | 本卷结尾与下载开篇的逻辑一致性 | □ 通过 □ 不通过 |

### 4. 伏笔回收

| 检查项 | 标准 | 判定 |
|--------|------|------|
| 本卷应回收伏笔 | 100%回收 | □ 通过 □ 不通过 |
| 本卷新种伏笔 | 标注清晰、计划回收卷合理 | □ 通过 □ 不通过 |
| 前卷未到期伏笔 | 未被误触回收 | □ 通过 □ 不通过 |

### 5. 世界设定一致性

| 检查项 | 标准 | 判定 |
|--------|------|------|
| 力量体系无崩坏 | 境界/法术/灵根设定遵守 | □ 通过 □ 不通过 |
| 科学设定无硬伤 | 基本的物理/生物规则遵守 | □ 通过 □ 不通过 |
| 病毒设定一致 | 感染规则/变异规则未前后矛盾 | □ 通过 □ 不通过 |

### 6. 叙事节奏

| 检查项 | 标准 | 判定 |
|--------|------|------|
| 连续平淡章节 | ≤3章 | □ 通过 □ 不通过 |
| 卷末高潮 | 有明显高潮段落 | □ 通过 □ 不通过 |
| 卷末钩子 | 能引向下一卷 | □ 通过 □ 不通过 |

---

## 质量门决策矩阵

| 检查结果 | 决策 |
|---------|------|
| 全部通过 | ✅ 放行，进入下一卷 |
| 仅P2问题（不影响主线理解的小问题） | ⚠️ 有条件放行，标记问题清单随附 |
| 有P1问题（影响阅读体验但不破坏剧情逻辑） | 🔴 退回修改后退改，3天内复检 |
| 有P0问题（人设崩塌/因果断裂/伏笔丢失） | 🔴 退回修改+增加一次"写手会诊"，复检不通过则停写 |
