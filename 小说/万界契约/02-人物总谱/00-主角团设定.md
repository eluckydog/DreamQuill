# 主角团设定 · 朋友五人组

> 这五个人在穿越前就是朋友——同一所大学的学生/不同专业。
> 他们彼此很熟悉，但在穿越后不知道对方也在这个世界。

---

| 角色 | 穿越前 | 穿越后灵兽 | 语种 | 契约者 | 核心功能 |
|------|--------|-----------|------|--------|---------|
| **陈牧之**（主角） | 中文系大四 | 白狐·E→S | 汉语/古代汉语最强 | 苏晚（女·18岁） | 规则改写者·领袖 |
| **林一然**（室友） | 英语系大三 | 灵雀·C→A | 英语最强 | 陆北辰（男·20岁） | 规则调用者·战术 |
| **宋知意**（朋友） | 法语系大二 | 夜猫·D→A | 法语最强 | 白未央（女·28岁·法官） | 规则演算者·军师 |

## 一、陈牧之（主角）

| 字段 | 内容 |
|------|------|
| **穿越前** | 22岁，某大学中文系大四，正在准备考研。古汉语文学方向。从小跟爷爷学文言文和书法 |
| **穿越后灵兽** | 雪域白狐（幼体→成年）。外貌：通体雪白，眼瞳金色，尾部有银色纹路——这是他第一次无意中使用汉语阵纹时留下的"烙印" |
| **灵兽级别路径** | E级（穿越时）→ D级（第2卷）→ C级（第4卷）→ B级（第6卷）→ A级（第8卷）→ S级（第11卷） |
| **核心能力** | 以汉语书写的阵纹可以改写规则的生效范围。在掌握了古代汉语后，可以创造全新的规则 |
| **性格** | 外表温和但意志极强。穿越前是那种"什么事都不着急"的人——穿越后被迫变得果断。他对孤独有极强的承受力——因为从小父母离异，他习惯了一个人 |
| **核心阵纹** | 最早学会的阵纹是"安"字——他给自己画的第一个阵纹，为了让心跳平静下来 |
| **说话风格** | 在灵兽形态下不会说话。通过书写阵纹与外界沟通时，用词极度精准——因为每个字都在消耗灵力 |
| **核心困境** | 他能改变世界的规则，但他无法让最想让他知道的人（苏晚·他的契约者）知道：他是一个人。 |

## 二、林一然

| 字段 | 内容 |
|------|------|
| **穿越前** | 21岁，英语系大三，陈牧之的室友。口语极好，因为从小在美国生活过六年，后来回国上学 |
| **穿越后灵兽** | 青羽灵雀 → 后进化为风翎雀。体型小巧的鸟类灵兽 |
| **核心能力** | 英语阵纹可以"调用"已存在的规则进行逻辑组合——相当于掌握了这个世界的API |
| **性格** | 外向、话多、乐观到欠揍——穿越后这成了他的保护色。实际上他比任何人都害怕孤独 |
| **与主角的发现** | 第3卷：他在一个废墟上留下了一段英文阵纹——"ANYONE LIKE ME?"——被主角发现 |
| **关键场景** | 第6卷：他第一次用英语阵纹创造了一条防御规则。成功后他把那句话改成了"ANYONE LIKE ME? I'M HERE."——这是他给其他穿越者留下的第一个"定位" |

## 三、宋知意

| 字段 | 内容 |
|------|------|
| **穿越前** | 20岁，法语系大二。陈牧之的高中学妹，考到了同一所大学 |
| **穿越后灵兽** | 夜影猫 → 夜瞳猫。灵巧的夜行灵兽，听力极强 |
| **核心能力** | 法语阵纹可以进行"规则演算"——预测规则变化的时间窗口。她的阵纹不改变规则——但能告诉你规则什么时候会变 |
| **性格** | 冷静、理性、略微疏离。她是最早接受"我们已经无法回到地球"这个事实的人 |
| **最独特的能力** | 她能"听"到规则的边界——就像人能听到空气中的白噪音一样 |
| **与主角团** | 第4卷被发现。她是被主角的汉语阵纹引来的——但她在靠近之前先用法语做了一个"规则预测"（计算了主角是否危险），确认安全后才现身 |

## 四、小林千夏

| 字段 | 内容 |
|------|------|
| **穿越前** | 20岁，日语系大二。中日混血，父亲是中国人，母亲是日本人。在两国都生活过 |
| **穿越后灵兽** | 月影玉兔 → 翠晶兔 |
| **核心能力** | 日语阵纹可以进行"规则模式匹配"——识别并复制规则生效的模式。相当于掌握了"规则模板" |
| **性格** | 温和、谨慎、观察力极强。她是最不容易被注意到的穿越者——因为她的灵兽是F级（兔子），没人会怀疑一只兔子的异常 |
| **与主角团** | 第4卷尾声被发现。她是最晚加入的——因为她的日语阵纹最弱，留下的"签名"需要很长时间才能被识别 |

## 五、赵墨言

| 字段 | 内容 |
|------|------|
| **穿越前** | 24岁，古文字学研一。整个大学城唯一一个能全文背诵《说文解字》的人 |
| **穿越后灵兽** | 墨鳞蛇 → 玄冥蛇。C级→S级（12卷结束时是全书最强的灵兽） |
| **核心能力** | 古代汉语阵纹可以创造或删除底层规则。他是唯一一个拥有这个世界"root权限"的穿越者 |
| **性格** | 沉默、寡言、有轻微社交障碍。他在古文字中比在人类社会中更自在。穿越成蛇是他最满意的事——"蛇不用说话。" |
| **核心地位** | 他是全书"不可轻易出手的王牌"。每一次使用古代汉语阵纹都会引发世界的规则震荡——会被"规则研究所"精确定位。 |
| **与主角团** | 第8卷才被发现。他独自活了8卷——因为他的古代汉语阵纹太强，每次使用都会被追踪，所以他几乎不用。他通过观察其他人的阵纹痕迹来确认"同类存在"。他不找他们的原因是——"如果我不被找到，就没有人能用我。" |

## 六、契约者（重要·非穿越者·但有独立弧线）

| 契约者 | 契约灵兽 | 年龄·身份 | 核心困境 | 弧线 |
|--------|---------|----------|---------|------|
| **苏晚**（主角的契约者） | 陈牧之（白狐） | 18岁·平民家庭·刚成年 | 她的灵兽太强了——但它是"不可控"的。她总觉得自己的灵兽想说什么却说不出来 | 从"普通女孩"→"世界上最强灵兽的契约者"→"第一个意识到灵兽可能是人类的契约者" |
| **陆北辰**（林一然的契约者） | 林一然（灵雀） | 20岁·佣兵家族 | 他的灵兽话太多——脑子里经常出现一个爱吐槽的"声音"（但他听不到具体内容） | 从"莽撞青少年"→"穿越者猎杀队的成员"→"背叛自己的阵营" |
| **白未央**（宋知意的契约者） | 宋知意（夜猫） | 28岁·规则法官 | 她的灵兽似乎比她更懂规则 | 从"规则的维护者"→"规则的质疑者" |
| **阿部正纪**（千夏的契约者） | 千夏（玉兔） | 22岁·武士家族末裔 | 他的灵兽是F级兔子——所有人都笑话他。他不知道这只兔子每天都在用日语计算"最安全的逃跑路线" | 从"被嘲笑的对象"→"用兔子打败了A级灵兽的人" |
| **容鹤**（赵墨言的契约者） | 赵墨言（墨蛇） | 45岁·规则研究所高层 | 他的灵兽太安静了——安静到可怕。他怀疑自己的灵兽有问题——但他不敢报告，因为一旦报告，他的灵兽会被处决 | 从"秩序的守护者"→"秩序的最大破坏者" |
