## 一、核心角色（贯穿全书12卷）

### 主角：陆沉

| 字段 | 内容 |
|------|------|
| **身份** | 原灵能实验室研究助理，24岁，科学背景 |
| **灵根** | 四品杂灵根（最差的那一档） |
| **境界** | 炼气三层（爆发前）/ 金丹初期（结局） |
| **核心困境** | 他太弱了——弱到丧尸懒得理他，但弱到任何危险都能杀他。他的存活不靠武力，靠"不被注意" |
| **核心动机** | 证明师父（在爆发中失踪）的理论是对的——"灵气的本质是一种能量场，可以被科学解析" |
| **核心能力** | 科学思维+炼气期低微灵力。他会用实验方法研究丧尸，而不是用剑砍。他是唯一一个从"科学角度"理解病毒的人 |
| **性格** | 内敛、谨慎、不热血。遇到危险的第一反应是躲起来观察，不是冲上去打。但一旦确认了目标和路径，会展现出惊人的执行力 |
| **说话风格** | 安静、精确。不轻易表态。思考时有摸鼻尖的习惯。不超过三个词的短句回答常见 |
| **外貌** | 普通身高，戴眼镜（近视+长期实验室工作的结果），手指有常年拿移液枪留下的茧 |
| **弧线（12卷）** | 实验室助理（1-2卷）→ 幸存者（3-4卷）→ 修仙者（5-6卷）→ 真相追寻者（7-8卷）→ 领袖（9-10卷）→ 终结者（11-12卷） |
| **3卷弧线** | 前三卷：从躲藏到第一次主动战斗（杀第一只丧尸） |
| **6卷弧线** | 中三卷：发现病毒真相+遇见觉醒者+面临道德选择 |
| **9卷弧线** | 后三卷：对抗幕后黑手+找到解药+终结修仙时代 |
| **与人设的铁律** | ①永远不会热血上头——即使愤怒也会冷静计算 ②他的"强大"来自知识不是武力 ③他对灵气本质的科学理解是全书唯一的"另一条路" |
| **关系锚** | ①与师父（失踪）：他的精神支柱，师父的理论指导了他的每一步 ②与江晚吟（女主角）：从互相瞧不上到彼此信任 ③与沈烛（觉醒者）："你到底是人还是丧尸"这个问题的反复拷问 |

### 女主角：江晚吟

| 字段 | 内容 |
|------|------|
| **身份** | 昆仑剑宗内门弟子，22岁，金丹初期 |
| **灵根** | 二品天灵根（顶级天赋） |
| **核心困境** | 她在旧秩序里是"天才"——但在新世界里，她的高修为意味着被丧尸盯上。她在逃亡中不能被任何人发现自己是金丹修士，否则会引来尸王级别的追杀 |
| **核心动机** | 找到失踪的宗门长老，那是她唯一的亲人 |
| **性格** | 外冷内热。骄傲但有底线。前期看不起凡人和低级修士（包括主角），后期被打脸然后成长 |
| **与主角的关系演变** | 第1-2卷：瞧不上他（"一个炼气三层的研究员能干什么"）→ 第3-4卷：互相救过命，开始尊重 → 第5-6卷：发现他的科学路径可能是对的，开始学习科学思维 → 第7-10卷：战友+灵魂伴侣 | 
| **说话风格** | 短促、命令式、偶尔的冷幽默。情绪化时用剑不用嘴 |
| **弧线** | 从"旧时代的精英"到"新时代的建设者"——她必须放下对修仙等级的执念 |
| **关系锚** | ①与主角：从轻视→尊重→信任→依赖 ②与失踪长老：她战斗的动力 ③与觉醒者沈烛：天然的对立立场 |

### 第二主角/觉醒者：沈烛

| 字段 | 内容 |
|------|------|
| **身份** | 感染后觉醒的丧尸，保有完整人类意识，25岁 |
| **感染前** | 昆仑剑宗外门弟子，炼气九层。在宗门被灭时感染 |
| **觉醒后能力** | 可以控制低级丧尸、感知丧尸群体的意识网络、肉体再生 |
| **核心困境** | 我还算人吗？我能被拯救吗？如果解药会杀了我，主角应该选解药还是选我？ |
| **性格** | 悲观的理想主义者。他比任何人都想拯救这个世界——因为他比任何人都清楚丧尸有多可怕。但他不接受"消灭所有丧尸=消灭我"的等式 |
| **弧线** | 第4卷出场（被主角当做研究对象）→ 第5卷建立信任→ 第6-7卷成为团队核心成员→ 第8卷面临"我是谁"的终极拷问→ 第11-12卷成为解药的关键 |
| **关系锚** | ①与主角："我是你的研究标本还是你的朋友"的反复拉扯 ②与江晚吟：她认为他应该被消灭——他不怪她 ③与幕后黑手：元婴老怪认为觉醒者是"进化的下一步"，沈烛是他要创造的新人类种族的原型 |
| **不可违背的铁律** | 他的丧尸身份永远不会被"治愈"——即使解药释放后，他也要花很长时间才能恢复人类状态。他的觉醒者身份是永恒的"灰色地带" |

### 宿敌/天道执行者：赤霄真人

| 字段 | 内容 |
|------|------|
| **真实身份** | 元婴后期散修，活了1300年，经历过上一次"灵气大清洗" |
| **表面身份** | 没暴露，在故事前半段以"隐居高人"的身份帮助主角团队 |
| **核心动机** | 他认为修仙文明已经到了"臃肿期"——太多低质量修士浪费灵脉资源，拖累了整个文明的进化。病毒是他的"进化工具"——淘汰弱者，筛选精英 |
| **灰度** | 他不是传统意义上的"邪恶"。他看到了修仙文明的隐患（灵脉枯竭、人口过剩、天才被埋没），他的方案极端但不无道理。主角到最后都有一部分理解他的逻辑——但无法接受他的手段 |
| **弧线** | 第8-9卷才暴露真实身份。前面作为"神秘帮手"出场，给主角提供关键信息和帮助。暴露时的反转应该是全书最大的"被背叛"体验 |
| **与主角的关系** | 师父的朋友 → 帮助者 → 导师 → 被揭露为幕后黑手 → 最终对决 |
| **说话风格** | 慢、有分寸、信息量大。每句话都有两层意思——一层是表面意思，一层是测试。喜欢引经据典然后用科学原理解释 |
| **不可违背的铁律** | ①他从不撒谎——他只选择性透露真相 ②他从不亲自杀人——他认为暴力是低效的手段 ③他的目标不是毁灭而是"进化"——这让他的行为逻辑比复仇更难以反驳 |

## 四、功能性配角库（示例20人）

这些角色没有独立弧线，是"按需取用"的工具人。写手在写某一章时需要某个功能的路人时，从这个库里取：

| # | 角色 | 功能 |
|---|------|------|
| F01 | 老张，50岁，前厨师 | 提供食物处理技能 |
| F02 | 小陈，19岁，前医学生 | 提供基础医疗支援 |
| F03 | 阿强，30岁，前健身教练 | 体力劳动担当 |
| ... | ... | （写手按需自取） |

**人物库使用规则：**
1. 功能性角色用完可以丢弃（不需要每人都回收弧线）
2. 但如果一个功能性角色出场超过3章，自动升级为"准配角"——需要补充弧线规划
3. 不要为了煽情随便杀功能性角色——读者会免疫
