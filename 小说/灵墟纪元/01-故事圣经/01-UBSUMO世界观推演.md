# UB-SUMO世界观推演 · 三大规则体系

## 一、触发判定：✅ 必须推演

三个规则体系相互作用，结构复杂程度超过之前的法盾系列：

| 规则体系 | 名称 | 核心机制 | 稳定性 | 利益相关者 |
|---------|------|---------|--------|-----------|
| 法则A | 修仙体系 | 灵气修炼→境界提升→寿元延长→天人感应。有完整的境界体系、功法体系、宗门制度 | 高（万年来稳定运行的秩序） | 宗门、散修、修仙家族、灵矿主 |
| 法则B | 现代科学/技术体系 | 物理/化学/生物/信息科技。电力、通信、医疗、武器。与修仙共存并互相渗透 | 中（科技在加速发展） | 政府、科研机构、军工企业、普通人 |
| 法则C | 丧尸病毒/T病毒 | 空气传播→感染→变异。核心特征：以灵气为能量来源和催化剂。灵气浓度越高，病毒活性越强 | 爆发期极低（秩序瞬间崩塌） | 感染者（丧尸）、免疫者、变异生物 |

**关键桥接点（STUbL）：灵气**
- 灵气是修仙的基础资源（法则A的核心底物）
- 灵气在科学体系的认知中是"一种尚未完全解析的能量场"（法则B的知识盲区）
- 灵气是丧尸病毒的最佳培养基——病毒以灵气为食，灵气浓度越高，病毒变异越快（法则C利用A的资源）

## 二、并联法则（爆发前的世界基线）

### 法则A：修仙体系（爆发前）

修仙已融入社会运转一万三千年。社会结构分为三层：

**上层：化神期以上修士（占人口0.003% ≈ 4万人）**
- 坐镇大宗门和国家级机构
- 掌握核心功法传承
- 寿元300-1500年
- 不直接参与世俗管理，但通过门人弟子影响世界

**中层：筑基-金丹修士（占人口2% ≈ 2600万人）**
- 各级政府部门、军队、企业的中高层
- 负责灵气能源的开采和应用
- 社会的中坚力量

**底层：炼气期修士（占人口12% ≈ 1.5亿人）**
- 普通修士，从事各行各业
- 可以用低级法术辅助工作
- 大部分终其一生无法突破筑基

**凡人（占人口86% ≈ 11亿人）**
- 完全感应不到灵气的普通人
- 依赖科技生活，与修炼界有明确的社会分工

**修仙的核心约束（写作时不可违反）：**
- 境界提升需要：天赋（灵根） + 功法 + 资源（灵石/丹药）+ 悟性 + 机缘
- 不是"努力就能突破"——瓶颈期可能卡十年到百年
- 功法有属性匹配（金木水火土+变异属性），不能乱练
- 高境界修士有"天劫"风险——突破大境界时有生死劫

### 法则B：现代科学/技术体系（爆发前）

灵气时代科技的特点：

- **灵能科技：** 灵力替代电力的能源体系。灵能发电站、灵能发动机、灵能护盾。核心城市有灵气护城大阵的现代版本
- **生物科技：** 灵植培育、灵兽基因改良、修士体质研究。科学界在尝试"人工灵根"项目（未成功）
- **信息技术：** 灵讯技术（用灵气传递信息，比5G快但只能由修士使用）、量子计算
- **医疗：** 普通疾病用科技治愈，修炼损伤用丹药和医术治疗。两者互补
- **军事：** 灵能武器（灵气炮/灵能护盾） + 常规武器。特种部队由筑基修士组成

**科技的核心约束（写作时不可违反）：**
- 无法制造灵石——灵石是自然矿物，不可再生
- 无法人工制造灵根——这是科学界最大的瓶颈
- 科技武器对高境界修士无效（金丹以上有灵气护体，导弹都打不穿）
- 但科技武器对筑基以下修士有效

### 法则A+B共存状态（爆发前的世界面貌）

社会已形成稳定的"双层结构"：

```
灵界（修士社会）     →      凡界（普通社会）
  宗门、灵脉、灵石    ←→    城市、科技、法治
  强者为尊的秩序      ←→    法律规范的秩序
  通过灵石贸易连接     →     通过税收和人才输送连接
```

存在政府机构"灵凡协调署"，负责处理两个体系之间的冲突。
不存在"修仙者统治一切"——高境界修士数量太少，不足以管理整个人类社会。他们更像"核武器"——存在本身就是威慑，不轻易使用。

## 三、通路级互作（病毒爆发→世界剧变）

### 爆发起点（第1卷内容）

**触发事件：** 一座失控的灵能实验室发生爆炸——实际是某个势力在研究"灵能武器"时出的事故。爆炸释放了大量被污染的灵气。污染灵气中含有一种能感染人类细胞的类朊病毒。

**初始感染：** 受影响区域的修士最先出现症状——因为他们的身体对灵气最敏感。病毒在体内复制时，以修士的灵力为能量来源。

**病毒的核心机制（世界观层面的关键设定）：**

```
感染条件：病毒通过空气传播进入人体
潜伏期：3-7天（取决于目标体内灵力浓度）
发病触发：当病毒复制到临界量，目标体内灵力被抽干→开始攻击神经系统

感染者状态：
  - 凡人感染 → 3天内变异为普通丧尸
    → 速度慢、攻击力低、无智力，捕食本能
    → 但对灵力有感知力，会被灵力吸引

  - 炼气期感染 → 1-2天内变异为强化丧尸
    → 速度快、有低级灵力反应、可释放生前掌握的低级法术（本能释放）
    → 体内灵力会持续吸引更强大的丧尸

  - 筑基期感染 → 极短时间内变异为"异化者"
    → 保留生前部分战斗记忆、有中等智力、可使用护体灵气
    → 对普通武器完全免疫
    → 是丧尸群中的"指挥官"

  - 金丹期及以上感染 → 变异为"尸王"
    → 生前智力大部分保留、可使用高阶术法、能统御大片区域的丧尸
    → 每一尊尸王都是一个移动的天灾
    → 全球尸王数量：极少数（高阶修士在爆发初期大多成功逃离或战死）

  - 特殊感染体（伏笔）：
    → 同时拥有丧尸特征和人类意识的变异体（"觉醒者"）
    → 不是治愈——是病毒与宿主意识达成共生的罕见状态
    → 发生率：百万分之一
```

### STUbL桥接节点链（12卷的骨架）

```
C0: 灵能实验室爆炸 → 污染灵气泄露（爆发起点） → 第1卷
  ↓
C1: 灵气成为丧尸催化剂 → 高浓度灵气的区域成为死域 →
    人类退守灵气稀薄区域 → 社会秩序崩塌 → 第1-2卷
  ↓
C2: 宗门死守灵脉 → 灵脉被丧尸围困 → 灵气资源断供 →
    灵能科技瘫痪 → 退回纯科技时代 → 第2卷
  ↓
C3: 修士群体萎缩（战死/感染/逃亡） → 凡人中的幸存者
    开始被迫修仙（以前没有机会/资格）→ 第3卷
  ↓
C4: 觉醒者出现 → 第一个保持人类意识的丧尸（伏笔C0的延伸）→ 第4卷
  ↓
C5: 幸存者基地建立 → 形成新的社会规则 →
    "灵根"不再是天赋特权——现在是生存能力的代名词 → 第4-5卷
  ↓
C6: 主角发现病毒的源头不是意外——是人为的。有人故意释放了病毒 → 第6卷
  ↓
C7: 觉醒者加入主角团队 → 揭示了病毒的上层控制机制 →
    尸王背后有"指挥者"存在 → 第7卷
  ↓
C8: 主角面临选择——摧毁所有丧尸 = 也杀死觉醒者（包括觉醒者同伴）→ 第7-8卷
  ↓
C9: 幕后黑手现身：一个活了上千年的元婴期老怪，试图用病毒
    清洗掉"低质量修士"，创造一个全部由高阶修士组成的新人类种族 → 第8-9卷
  ↓
C10: 主角团队找到病毒的解药——但解药需要释放一种反灵气能量，
    这种能量会永久污染地球上的所有灵脉，修仙文明将终结 → 第9-10卷
  ↓
C11: 决战——主角不是靠武力战胜元婴老怪，而是利用病毒本身的
    特性（病毒以灵气为食 → 让老怪体内的灵气成为他的致命弱点）→ 第11卷
  ↓
C12: 终局——解药释放。丧尸被治愈（包括觉醒者恢复人类意识）。
    但灵脉也被永久污染了。修仙时代终结。幸存者将在一个
    没有灵气的世界里重建文明——带着修仙时代的记忆和科学技术的知识 → 第12卷
```

## 四、分支拓扑（可选演化路径）

### 主线（采用路径A：平行演化→新秩序）

```
病毒爆发 → 短期全面失控 → 幸存者建立新规则
→ 在丧尸威胁下被迫修炼 → 发现真相 → 决战
→ 终结修仙时代 → 开启后灵气时代
```

### 暗线（续集/番外路径B：吞并重构）

```
如果主角选择不释放解药：
→ 人类与丧尸长期共存 → 觉醒者成为新物种
→ 形成"人族+觉醒者+尸王"三方割据
→ 修仙文明在废墟中延续但已变质
→ 这个故事比主线更暗、更适合成年读者
```

### 续集种子（路径C：平行演化）

```
解药释放后 → 灵脉污染 → 灵气缓慢消散需要30-50年
→ 在这期间，最后一代修士用最后的灵力做最后的抗争
→ 而丧尸病毒在低灵环境中出现了新的变异方向...
```

## 五、世界观的核心情感基调

这不是一个"修仙者拯救世界"的故事。
这是一个**普通人在修仙时代结束后，用科学和意志重建世界**的故事。

**核心主题：** 当旧的规则体系（修仙）崩塌，新的规则体系（丧尸威胁+求生）建立时——夹在中间的普通人如何找到自己的路。

**情感锚点：** 不是"变强打怪"的爽——是**在绝望中抓住一丝希望、在废墟中种下一颗种子**的悲壮与温暖。

**故事的气质：**
- 前期（1-4卷）：末日求生的压迫感+修仙世界崩塌的苍凉
- 中期（5-8卷）：探索真相+新秩序的艰难建立+觉醒者的道德困境
- 后期（9-12卷）：直面幕后真相+终极选择+告别一个时代
