# 12卷总纲与因果链图谱

## 全卷结构一览

```
第1-2卷 · 灰域求生（20万字）
  └── 世界观建立+主角觉醒
第3-4卷 · 被迫修仙（20万字）
  └── 新规则+第一次突破+觉醒者出现
第5-6卷 · 真相浮现（18万字）
  └── 病毒不是意外+主角的科学理论得到验证
第7-8卷 · 抉择与代价（18万字）
  └── 觉醒者的困境+赤霄真人现身
第9-10卷 · 终极之战（20万字）
  └── 解药找到+代价是终结修仙时代
第11-12卷 · 终局与新纪元（18万字）
  └── 决战+告别一个时代
```

## 逐卷详情

### 第1卷《灰域初醒》（10万字）

| 因果 | 内容 |
|------|------|
| **主链节点** | C0-C1 |
| **核心功能** | 建立世界观+病毒爆发+主角从实验室逃出 |
| **开场** | 主角在灵能实验室日常工作时听到爆炸声——第三节气体从通风管道涌入 |
| **中段** | 实验室被封锁→同事被感染→主角目睹第一个同事变成丧尸→逃生 |
| **卷末高潮** | 主角逃到地面，发现城市已沦陷。第一次使用灵气（本能性）保护自己不被丧尸发现——"弱到不会被注意"第一次成为生存优势 |
| **卷末钩子** | 一个高级修士（江晚吟）从天上坠落，砸在主角面前的车顶上。她全身是伤。远处，一只尸王正在靠近 |
| **本卷POV** | 主角100% |
| **本卷新角色** | 陆沉（主角）·江晚吟（出场）·师父陈道远（回忆）·林若（出场后退场）·赵无畏（登场） |

### 第5卷《赤霄之影》（9万字）——示例中卷结构

| 因果 | 内容 |
|------|------|
| **主链节点** | C6-C7 |
| **核心功能** | 主角发现病毒的源头不是意外——是人为的。这是全书最大的转折点之一 |
| **开场** | 主角在基地的实验室里研究丧尸样本，发现了一个异常的DNA序列——不像自然突变，像人工编辑 |
| **中段** | 主角追踪DNA序列的来源→找到一本赤霄真人遗落的笔记（里面有病毒设计的原始草图）→但赤霄真人在此时是"帮助者"身份，主角以为是别人嫁祸给他→江晚吟发现笔记上的灵力印记与"师父的朋友"一致 |
| **卷末高潮** | 赤霄真人现身——不是来战斗的，是来对话的。他告诉主角："病毒是我释放的。但如果你认为我是反派——你先听我说完理由。" |
| **卷末钩子** | 赤霄真人说完了他的理由（修仙文明的淘汰机制）。主角发现自己部分同意他的逻辑——但完全不同意他的手段。世界观崩塌 |
| **本卷POV** | 陆沉（80%）+ 江晚吟（20%） |
| **本卷字数分布** | 第1章8,000 / 第2章8,000 / 第3章8,000 / 第4章7,000 / 第5章8,000 / 第6章8,000 / 第7章9,000 / 第8章7,000 / 第9章9,000 / 第10章8,000 / 第11章6,000 / 第12章4,000 |

### 第12卷《最后一代修士》（8万字）

| 因果 | 内容 |
|------|------|
| **因果节点** | C12 |
| **核心功能** | 收束全部线索+情绪释放+告别 |
| **开场** | 解药释放后的第三十天。丧尸在缓慢恢复人形。灵脉在缓慢变黑。修仙时代的倒计时开始了 |
| **中段** | 沈烛在痛苦中恢复了人类意识——他是最后一个被"治愈"的觉醒者。他与江晚吟的对话：沉默多于语言。赤霄真人被废去修为，关在基地地下——他将亲眼见证他想要终结的文明如何终结 |
| **卷末高潮（三段式）** | ①最后一剑：江晚吟用尽最后的灵力，在一座即将枯竭的灵脉上练了一趟剑法——没有敌人，没有观众。她只是在和她的时代告别。②最后一次实验：陆沉测出了灵脉污染的最终数据——300年后，地球上的灵气将完全消失。他把数据记录在册子上，封面写着《修仙时代终结报告》。③黄昏：主角团队爬上基地最高的楼顶，看日落。没有人说话。远处，一个曾经是尸王的巨型身影正在缓缓跪下——它体内的病毒也在死去 |
| **终章（后记式）** | 30年后。陆沉和江晚吟的孩子出生——检测没有灵根。陆沉笑了笑说："那就好好读书吧。"——最后一句话，全书的主题 |
| **本卷POV** | 陆沉+江晚吟交替 |
| **字数** | 短卷，8万字。不让读者在结尾觉得拖沓 |

## 全书因果链全览

```
C0 ── 灵能实验室爆炸，污染灵气泄露 ────────────── 第1卷前
  ↓
C1 ── 灵气成为丧尸催化剂，秩序崩塌 ─────────────── 第1卷
  ↓
C2 ── 宗门死守灵脉→被丧尸围困→灵能时代终结 ────── 第2卷
  ↓
C3 ── 凡人中的幸存者被迫开始修仙 ───────────────── 第3卷
  ↓
C4 ── 觉醒者（沈烛）出现 ─────────────────────── 第4卷
  ↓
C5 ── 幸存者基地建立，新规则形成 ───────────────── 第4-5卷
  ↓
C6 ── 陆沉发现病毒有人工编辑痕迹 ───────────────── 第5卷
  ↓
C7 ── 赤霄真人现身，承认释放病毒 ───────────────── 第5-6卷
  ↓
C8 ── 赤霄真人说出"进化论"逻辑 ────────────────── 第6卷
  ↓

  ↓
C10 ─ 赤霄真人的追随者反扑 ────────────────────── 第9-10卷
  ↓

  ↓
C12 ─ 解药释放。修仙时代终结。新纪元开始 ────────── 第12卷
```

**三大暗线（不写在主链上，但贯穿全书）：**

```
暗线A：师父陈道远的去向（第1卷失踪 → 第6卷发现他还活着 → 第10卷再见）
暗线B：沈烛的"自我认知"（我是不是人？从第4卷拷问到第12卷）
暗线C：灵气的本质——陆沉的科学研究（从第1卷到第11卷逐步验证理论）
```
