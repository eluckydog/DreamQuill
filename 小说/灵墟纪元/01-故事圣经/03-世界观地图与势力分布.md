# 世界观地图与势力分布

> 写手写作时遇到"这个地方在哪里"时查阅。
> 地图概念化——不需要精确地理坐标，知道相对关系和特征即可。

---

## 一、大晟朝（平行世界·东亚核心区域）

一个幅员约等于中国+东南亚的超级大国。"灵气版现代中国"——地理大致相同，但地名根据灵气时代的历史演变有所不同。

### 核心区域

| 区域 | 特征 | 爆发后的状态 |
|------|------|-------------|
| **灵都（原京都）** | 灵脉最密集区，修仙文明的心脏。三大超级宗门所在地 | **死域。** 灵气浓度太高→聚集了最多的丧尸+尸王。完全封锁，不可进入 |
| **昆仑城** | 西部第一大城，昆仑剑宗所在地 | **沦陷。** 第2卷宗门被破，第5卷变成废墟 |
| **东海市** | 东部沿海科技中心，灵能实验室在此。**主角所在地** | **第1卷爆发地。** 前三卷的主要舞台，后逐步被放弃 |
| **西蜀基地** | 地势险要+灵气稀薄→丧尸少→幸存者聚集 | **第3卷后主要基地所在地。** 全书的"家" |
| **南疆灵脉** | 热带灵脉区，灵气稀薄但有稀有灵植 | 第7-8卷探索区域 |
| **北境废墟** | 灵脉枯竭区，几乎没有灵气 | 第9-10卷穿越区域——赤霄的老巢 |

### 灵气浓度地图（示意）

```
灵气浓度示意：
  灵都 ████████（不可进入）
  昆仑 ██████（第2卷后崩塌）
  东海 ████（从第1卷的"中浓度"逐步下降）
  西蜀 ██（低浓度→安全但资源少）
  北境 █（几乎为零→极端环境→赤霄的老巢在这里）
```

## 二、势力分布

### 爆发前的主要势力

| 势力 | 性质 | 爆发后状态 |
|------|------|-----------|
| 昆仑剑宗 | 三大超级宗门之一，以剑道著称 | 第2卷覆灭 |
| 天道宗 | 三大超级宗门之一，研究天道规律 | 位置在灵都→被丧尸包围，与外界完全隔绝 |
| 碧落宫 | 三大超级宗门之一，偏女性修士 | 第3卷后撤入秘境，第8卷秘境也被攻破 |
| 灵凡协调署 | 政府机构，管理修士与凡人之间的关系 | 第2卷后实际上已经不存在了 |
| 灵能研究院 | 主角陆沉的工作单位 | 第1卷崩了 |
| 军方 | 常规军队+修士特种部队 | 第1-2卷被打散，少量残部加入幸存者基地 |

### 爆发后的新生势力

| 势力 | 建立者 | 性质 | 覆盖卷 |
|------|--------|------|--------|
| **西蜀安全区** | 赵无畏 | 最大的幸存者基地，主角团队的大本营 | 第2-12卷 |
| **赤霄追随者** | 赤霄真人 | 秘密组织，认为病毒是"进化工具" | 第5-11卷 |
| **猎尸会** | 周独龙（草创） | 赏金猎人式的丧尸猎杀组织 | 第2-10卷 |
| **觉醒者** | 沈烛（唯一） | 保持人类意识的感染者——只有他一个 | 第4-12卷 |
| **尸王议会** | 无名等 | 丧尸中的高阶存在，有初步的组织意识 | 第7-10卷 |

### 幸存者基地的内部架构（第3卷后逐步形成）

```
基地首领：赵无畏
  ├─ 战斗部（周独龙→后由江晚吟负责）
  ├─ 研究部（陆沉+林若）
  ├─ 后勤部（老张/王姐等）
  ├─ 医疗部（白素+小陈）
   └─ 情报部（花娘的外部网络）
```
